# == VectorLib 1.0.2 ==

## Additions
- Added some more contributor capes
- Added several name tag easter egg skins for mobs, ported from *Frontiers*
  - The following names have been added:
      - Parrot: "Kazooie", "Lovebirb", "Keynis"
      - Snow Golem: "Admin", "Romeo"
      - Rabbit: "SuperSMZ", "Oopr"
  - These can be disabled by setting `entitySkinEasterEggs` to `false` in the config, just in case these break things

## Changes
- Changed a few text responses with commands, nothing too noticeable

## Fixes
- Fixed an issue where the server would instantly crash because splashes tried to register on it
