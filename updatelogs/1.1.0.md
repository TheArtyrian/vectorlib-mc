# == VectorLib 1.1.0 ==

## Additions
- Added `VectorJoinMsgMan`, which handles contributor join/leave messages
- Added several cape-related functions based on work I did on NexusLib & RunicLib:
  - `VectorCapeMan`: A dual-sided handler for custom contributor capes
  - `VectorClientCapeMan`: A client-sided system for remembering a user's cape, when applicable
  - `VecCape`: A representation of a custom cape in VectorLib
  - Capes can now be changed or disabled via the Skin Settings menu
  - Removed the client-sided cape display option from the config
  - Added some more contributor capes

## Changes
- Separated `VectorSystems` into several smaller classes in an effort to static-ify it. Not really important.
- Added an easter egg that I accidentally forgot to separate from *Frontiers*
